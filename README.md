# Innova AI - Multi-Agent Performance Review Platform

A robust, AI-powered platform for generating completely objective, evidence-backed employee performance reviews using a multi-agent architectural pipeline.

## 🎯 Problem Statement
Traditional performance reviews are notoriously biased, subjective, and prone to recency bias or manager dominance. HR systems often lack objective transparency, relying on a single manager's unchecked opinions. 

## 💡 Solution
Innova AI mitigates bias by introducing a strictly moderated, evidence-grounded **Human-in-the-Loop Multi-Agent Pipeline**. By consuming a wide variety of empirical telemetry (e.g., project goals, tickets, peer feedback, self-assessments), the AI builds comprehensive and balanced drafts that flag biased language and demand transparent evidence for every single claim.

---

## 🏗️ Architecture & Multi-Agent Workflow

Innova relies on a sequential state-graph composed of 4 distinct AI agents.

1. **Collector Node:** Aggregates unstructured and structured feedback across disparate data sources (self-assessments, peer feedback, goal metrics, and meeting transcripts).
2. **Retriever Node:** Converts the collected feedback into chunked vector embeddings, performing RAG (Retrieval-Augmented Generation) to fetch only the most relevant, highly-correlated evidence for the target review period.
3. **Synthesizer Node:** Takes the semantic chunks and generates structured JSON output (strengths, growth areas, etc.). *Crucially, if it makes a claim, it must provide a strict citation mapping to an evidence chunk. Unsupported claims are flagged with low confidence.*
4. **Auditor Node:** The "Bias Check" agent. It reviews the Synthesizer's output against common heuristic biases (Halo effect, Horn effect, Recency bias, Subjective language) and generates actionable **Audit Flags** with varying severity levels to warn the human manager.

---

## ✨ Features

- **Evidence Grounding:** Every statement generated by the AI is strictly mapped to an evidence chunk (e.g., a specific goal completion or a documented peer comment). Hallucinations are actively suppressed.
- **Bias Detection:** Automatic tagging of subjective language or rating inflation/deflation, protecting employee evaluations.
- **Human-in-the-Loop Workflow:** AI does not make the final call. Managers are provided with the drafted review, a confidence score, and bias audit flags. They must manually accept, edit, or reject the AI's suggestions before finalizing.
- **Governance & Privacy:** All generated reviews are strictly tracked. The platform implements robust API rate limiting, LLM retry mechanisms, and logs generation events for HR auditability.

## 💻 Tech Stack

- **Frontend:** Next.js (App Router), React 18, Tailwind CSS, TypeScript
- **Backend/API:** Next.js Serverless APIs
- **Database:** Prisma ORM with SQLite (libsql)
- **AI/LLM Engine:** Groq API (openai/gpt-oss-120b)
- **State Orchestration:** Custom sequential pipeline graph

## 🚀 Setup & Environment Variables

### 1. Install Dependencies
\`\`\`bash
npm install
\`\`\`

### 2. Configure Environment Variables
Create a \`.env\` file in the root directory:
\`\`\`env
# Database
DATABASE_URL="file:./dev.db"

# Authentication
NEXTAUTH_SECRET="your-super-secret-key"
NEXTAUTH_URL="http://localhost:3000"

# AI Provider
GROQ_API_KEY="your-groq-api-key"
GROQ_MODEL="openai/gpt-oss-120b"
\`\`\`

### 3. Initialize Database
\`\`\`bash
npx prisma generate
npx prisma db push
\`\`\`

### 4. Run the Application
\`\`\`bash
# Run web application
npm run dev

# Run automated standalone multi-agent tests
npm run test:agent
\`\`\`

## 🛡️ Security & Reliability
- **Graceful Fallbacks:** The LLM orchestration utilizes \`AbortController\` for 15s timeouts and implements exponential backoff on HTTP 5xx errors to ensure UI reliability.
- **Rate Limiting:** In-memory request tracking prevents endpoint abuse.
- **Data Sanitization:** PII masking logic within the Collector Node ensures sensitive data constraints are respected before hitting external LLM endpoints.
